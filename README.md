# Smart-health-detection-for-coma-patients
Smart Health Detection for Coma Patients is an IoT-based healthcare monitoring system designed to track the vital signs of coma patients in real time. These readings are processed by a microcontroller and sent to a monitoring platform where caregivers or medical staff can easily observe the patient’s condition.


Smart Health Detection for Coma Patients is an IoT-based healthcare monitoring system designed to continuously track the vital signs of patients who are in a coma or unable to communicate their health condition. The system monitors important parameters such as heart rate, body temperature, and oxygen levels, helping caregivers and medical professionals observe the patient’s health in real time.

The collected data is processed using a microcontroller and can be viewed remotely through a monitoring interface. If any abnormal readings are detected, the system can generate alerts to ensure immediate medical attention.

This project aims to improve patient safety, enable remote monitoring, and reduce the need for constant manual observation.
